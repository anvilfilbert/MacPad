# MacPad 1.0.9 Security Review

This is a historical review of release 1.0.9, completed on 2026-08-07. It is not the current security policy. See [`SECURITY.md`](../../SECURITY.md) for supported versions and vulnerability reporting.

## Executive Summary

MacPad is a native, offline macOS plain-text editor. It has no network client, authentication, server, database, analytics, or third-party Swift package dependencies. This review found no critical or high-severity vulnerabilities.

The 1.0.9 hardening closed identified document-integrity, unsafe file-decoding, session-validation, command-routing, and release-provenance gaps. Twenty-three automated core and AppKit tests covered those regressions at release time.

## Resolved Findings

### S-001: External changes could be overwritten

**Severity:** Medium

**Status:** Fixed in 1.0.9

MacPad records a SHA-256 digest when a file is loaded and verifies the current file immediately before saving. A mismatch stops the save and offers Save As, Reload from Disk, or Cancel.

### S-002: Symbolic links and special files needed defensive handling

**Severity:** Medium

**Status:** Fixed in 1.0.9

File URLs are resolved before loading or saving. Reads use an open file descriptor plus `fstat`, require a regular file, enforce the 25 MB limit before and during reading, and reject directories and other special files.

### S-003: Arbitrary bytes could be treated as text

**Severity:** Medium

**Status:** Fixed in 1.0.9

MacPad validates supported plain-text encodings, rejects binary-like control data, preserves detected encoding and line endings, and fails instead of performing lossy conversion.

### S-004: Session validation and persistence were too permissive

**Severity:** Low

**Status:** Fixed in 1.0.9

Session decoding bounds window and tab collections, clamps cursor and zoom values, removes malformed state explicitly, and stores file paths and UI metadata without document text.

### S-005: Utility panels could redirect document commands

**Severity:** Low

**Status:** Fixed in 1.0.9

Find and Replace use a non-main utility panel. Document commands resolve the main editor before utility panels, and duplicate external-open requests reuse an existing editor.

### S-006: Release provenance and CI coverage were insufficient

**Severity:** Medium

**Status:** Fixed in 1.0.9

CI runs tests, scans public content for private-data patterns, verifies the universal release package, pins GitHub Actions to full commit SHAs, and publishes build-provenance attestations.

## Accepted Distribution Constraint

GitHub builds are locally signed but not Apple-notarized. Developer ID distribution requires paid Apple Developer Program membership and private signing credentials. Release documentation discloses the resulting Gatekeeper warning.
