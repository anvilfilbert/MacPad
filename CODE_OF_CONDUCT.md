# Code of Conduct

MacPad follows the [Contributor Covenant Code of Conduct](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

Be respectful, constructive, and direct. Harassment, personal attacks, and abusive behavior are not acceptable in issues, pull requests, discussions, or other project spaces.

For a private conduct report, use a private contact method listed on the [project owner's GitHub profile](https://github.com/anvilfilbert). Do not include sensitive conduct reports in public issues or security advisories. GitHub's [Report Abuse](https://support.github.com/contact/report-abuse) form is available for platform-level abuse.
