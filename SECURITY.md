# Security Policy

## Supported Versions

Only the latest public release is supported.

## Reporting a Vulnerability

Please do not open a public issue for a security vulnerability.

Use [GitHub private vulnerability reporting](https://github.com/anvilfilbert/MacPad/security/advisories/new). Include:

- A clear description of the issue
- Steps to reproduce
- Impact and affected versions
- Any suggested mitigation

Security reports will be reviewed before public disclosure.
